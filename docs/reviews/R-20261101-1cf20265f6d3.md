## Change and reference

The shared tree hit API resolves the visible clicked row without changing
selection, expansion, focus or capture, excluding padding, scrollbars and
occlusion. Shift+F10 opens the corresponding context menu. Detach defaults to
Cancel, explains volatile attachments, rejects cell/external drafts, workers
and actual pending writes, and releases only clean read transaction locks.
Qualified Browse caches/settings, Schema sessions, conditional rules and
table Plot configurations reconcile; independent SQL/DDL drafts and SQL result
snapshots remain. Other aliases and database files are retained. Dependent
TEMP views report unavailable results instead of retaining stale rows.

Original v3.13.1 references: [MainWindow.cpp](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/MainWindow.cpp)
and [sqlitedb.cpp](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/sqlitedb.cpp).
SQLite's [DETACH documentation](https://sqlite.org/lang_detach.html) describes
independent aliases of the same file. Tests cover that behavior and verify
the database file bytes are unchanged. The example requires explicit Write
Changes/Revert before Detach, avoiding implicit transaction decisions.
