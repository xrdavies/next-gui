  cycle focus; Enter/Space activates it; Escape dismisses. Wrapped body height is
  measured. Existing builder calls keep their two-action behavior. Public
  `ModalAction::Tertiary` requires downstream exhaustive matches to add a branch;
  e15 was updated and all workspace callers compile.
- `a0f567b`: one transition dispatcher protects database/project/SQL/DDL/cell/PRAGMA
  changes with Save/Discard/Cancel. Destination dialogs run before writes; cancel
  preserves the session. Apply uses the same typed cell validation as the dock.
  Save As retains tabs/settings rather than resetting the workspace. A failed
  save reports incomplete work and keeps documents open. Multiple file/database
  saves are not a cross-file atomic transaction.
- `10e3e76`: SQL tabs bind to source paths, display file names/dirty markers, save
  atomically and reject an externally changed source. Save As, Close Tab, move
  arrows and Cmd/Ctrl+T/W/S/Shift+S work through shared action handlers even with a
  hidden toolbar. Text, file binding, editor session and results move together.
- `6aeb50e`: closing one SQL tab saves/discards only that document. Cancel keeps it;
  other drafts and pending database writes remain intact. Clean tab close does
  not prompt about unrelated database changes. Per-tab saved baselines ensure
  dirty markers follow reordered unbound tabs and the final blank tab is clean.
- `08b07f1`: compact typography, neutral toolbars, semantic primary actions and
  light/dark surfaces. Pane widths adapt at 800×600; dragged body/structure ratios
  survive rebuilds and projects. Long action strips scroll. Full docking, visible
  scrollbars and filter/grid geometry alignment remain absent.
- `c4286c0`: shared Font fallback stacks choose the same face for measurement,
  layout and rasterization. Primary baseline metrics remain stable. e28 appends
  Apple Symbols to its CJK face on macOS; missing dropdown/tree symbols now render.
  This does not supply complex-script shaping or grapheme navigation.
- `4b69e6e`: `.sqbpro` output uses DB4S XML; legacy JSON remains readable and a
  `.json` destination writes JSON. The installed quick-xml 0.41 parser is reused.
  Core database/SQL paths and references, access mode, five connection PRAGMAs,
  existing attachments, main-schema browse widths/primary sort and current tabs
  restore. Unknown elements/attributes survive save, with a next_gui extension
  for local state. Advanced filters/formats/plots, Qt dock state and attached
  browse tabs are retained but reported as unapplied. This is partial interchange.
  Connection/file preflight precedes replacement, read-only attachments use URI
  read-only mode, invalid XML/identifiers/settings fail explicitly, DTD/external
  entities are rejected, and XML is bounded to 16 MiB / 64 levels. SQLCipher keys
  are not serialized. Linked SQL is read from its source before replacing a session.
