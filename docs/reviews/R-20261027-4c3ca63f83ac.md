## Scope and macOS parity

Upstream [ExtendedScintilla.cpp at v3.13.1](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/ExtendedScintilla.cpp) enables margin line numbers and sizes the gutter by digit count. Shared TextArea adds an optional physical line-number gutter through `Ui::set_text_area_line_numbers` and DSL `line_numbers`; the default stays off. Public style struct literals, dependencies and disk formats are unchanged. Main SQL and the Find overlay enable the feature before restoring editor sessions.

Gutter width is reserved by the same layouts used for paint, pointer placement, vertical/page keys, scroll bounds and composed IME cursor placement. Only visible physical numbers are rasterized; wrapped continuation rows have no extra number. Empty documents and final blank lines are numbered. Width grows at decimal boundaries, with bounded clipping at tiny widths. Numbers remain separate from document content, selected-text copy, search and undo. An opaque session records the prior presentation mode to discard stale pixel goals/reveal on a mode change; restoration keeps the destination mode.

An initial new test used `.as_slice()` on the raster mask's `Arc<[u8]>`; the compiler rejected that test call. It was corrected to `.as_ref()` without changing production rendering. All final checks passed. No additional findings found.
