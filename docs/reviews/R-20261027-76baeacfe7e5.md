## Scope and reference

The original [SqlUiLexer](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/SqlUiLexer.cpp) provides function APIs with argument names and descriptions. This slice adds the underlying passive hint and runtime arity workflow; it does not yet replace that descriptive API surface. SQLite's [function_list PRAGMA](https://www.sqlite.org/pragma.html#pragma_function_list) supplies connection-specific signatures. They are cached on metadata refresh, so typing does not execute editor SQL or require ownership of the live connection.

`Ui::set_text_area_hint`/`text_area_hint` use scalar anchors and the same numbered/wrapped TextArea geometry as IME. The editor keeps focus. Hints hide under menus/composition and after stale state, with Escape suppression retained in matching editor sessions. `Scene::hit_test_excluding` lets passive hint nodes pass pointer/wheel hits through. Tooltip painting now bounds/wraps/clips text and flips above its host near the lower window edge; only the current host's tip remains visible. No dependency, database-write or project-format change.
