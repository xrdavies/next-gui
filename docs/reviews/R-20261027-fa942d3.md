## Scope and implementation

Browse refresh now counts rows with the exact same validated filter used by the
preview, including column and global filters. The current page range and total are
stored as transient browse state, shown in the status bar and toolbar, and used to
stop the next-page action at the last page. Empty browse pages report `0–0 of 0`.
The count query goes through the same read-only single-statement guard as the data
preview, so a tail statement cannot execute during navigation.

and rowid semantics while avoiding an unbounded synchronous count on huge datasets.
