## Scope and macOS parity

Upstream v3.13.1 MainWindow::populateStructure iterates db.schemata for qualified objects. SQLite documents [qualified names and temp-first lookup](https://sqlite.org/lang_naming.html), and [per-database schema tables](https://sqlite.org/schematab.html). The latter removes TEMP/database qualifiers from stored CREATE statements, so attached/temp previews must not be executed implicitly against main.

The live catalog now enumerates PRAGMA database_list and separately quoted sqlite_schema tables; empty databases remain visible. Object identity carries schema/type/name through selection, definition context, project serialization and confirmed DROP. Existing main-only browse/plot/wizard paths explicitly target main. New optional selected_object project data defaults safely for older files and round-trips through the next_gui XML extension. New/Close clear the old definition after document decisions; Save As refreshes the connection catalog. Main-only export/dump helpers retain main scope.

Attached/temp definitions are read-only previews and their structured Modify/Run DDL routes are disabled/guarded. Qualified Execute SQL remains available. This is an explicit implementation limit, not completion of attached browsing/creation/modification. No dependency or shared framework/painter change.
