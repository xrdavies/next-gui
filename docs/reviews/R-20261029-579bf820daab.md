## Resulting behavior

Save… opens the original format set (PNG/JPG/PDF/BMP, plus JPEG alias). Output uses
the visible Cartesian surface dimensions and its current viewport, palette, series,
legend and selection. Unknown extensions receive an appended .png, matching the
[original PlotDock save behavior](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/PlotDock.cpp).
The existing image dependency supplies BMP with one enabled feature; no new crate.

The shared Chart exposes its last drawing-surface size and existing image renderer.
All output is encoded to a private temporary file beside the destination and synced
before atomic replacement. Open main/attached databases and journal paths are guarded
before writing and again before publication. Failed encoding preserves old output,
and saving never commits pending database edits or replays the SQL source.
