## Implementation and original behavior

Original [dock visibility handling](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/MainWindow.cpp#L1038)
avoids reloading a cell while editing or docking, and [EditDialog](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/EditDialog.cpp)
uses persistent editor widgets. The example now captures existing TextArea/TextInput
sessions for the same loaded cell. A revision invalidates sessions on loading a
cell, changing its mode or replacing its contents, even when the new text is
identical. Stale widgets cannot overwrite replacement model values. Hidden
panels retain the session; unrelated rebuilds restore matching focus and IME
composition after sync, following the existing SQL editor pattern.

Native verification exposed a separate reload on range-anchor changes after
Undo reached the saved value. Polling now updates range metadata while loading
cell contents only when the selected row/column endpoint changes. The regression
covers the actual polling path; final native Undo/Redo pixel comparisons pass.
