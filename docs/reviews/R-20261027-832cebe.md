## Scope and implementation

CSV file import now detects UTF-16LE and UTF-16BE BOMs and decodes surrogate pairs
with the standard library before entering the existing multiline parser. UTF-8
behavior, BOM stripping, delimiter/header/quote options, strict field counts and
atomic insertion are unchanged. Odd-length or malformed UTF-16 data returns a
specific error before any database write.
