## Changes

DB Schema replaces its flat list with independent database/object/field nodes,
including temp, attached databases, views and generated fields. A filter retains
matching ancestors, expands matches without replacing the unfiltered expansion
state, and keeps input selection/history through rebuilds. Selection uses full
identifier paths, not node positions. A resizable read-only SQL preview retains
its matching source session. Database replacement/Close resets the dock session.

Insert/Enter replaces the current SQL selection as one undoable edit; Insert
SQL/Shift+Enter inserts the definition, and Browse/Cmd-or-Ctrl+Enter switches to
the qualified table/view. The options menu persists SELECT generation for tables
and views, qualification and quoting with backward-compatible defaults. Actions
reject stale objects, pending cell drafts and busy/background-owned connections.
Inserted SQL is never executed by these actions.

The existing SQL catalog now indexes its cached qualified column names for the
dock. Building/filtering the tree performs no database queries and avoids a
full completion-entry scan for every object. No dependency or framework/backend
change is required for this slice.
