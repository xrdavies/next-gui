## Scope and implementation

The shared Table now tracks an inclusive column range alongside its row range.
Shift+Left/Right extends the column range and Shift+Up/Down extends rows without
losing the other axis. Copy serializes a selected rectangle as TSV, while a row-only
selection keeps the existing full-row copy behavior. Cell selection backgrounds use
per-cell fills, and public setters restore active cells/ranges after a rebuild.
e28 stores the transient column range and starts TSV paste at the rectangle's
upper-left column.
