## Changes and reproduction

The existing shared menu supported nested items, but did not bound tall panels
or scroll their rows. Before the fix, the new dropdown/context-menu regression
failed at `panel.y >= 0.0 && panel.y + panel.height <= 160.0`.
Commit `3de661c91c837d6b52d7ecef53be64160b522969` bounds root and child panels,
keeps offsets per submenu, and reveals keyboard selections after navigation
and resize. Hit testing and child placement account for scroll offsets and
separator heights. Wheel input is consumed at the panel boundary; scrolling
an ancestor closes deeper panels, and reopening clears previous offsets.

SQLiteBrowser now uses the original v3.13.1 `MainWindow.ui` File Import,
Export and Recent Files hierarchy and File/Edit grouping. Existing leaf IDs
and guarded handlers remain intact. Menu typography follows the preference.
The old recent-path expression `&path[path.len()-47..]` panics on a long
mixed CJK/emoji path whose cut lies inside a UTF-8 character; an isolated
reproduction confirmed that panic. The new display keeps valid UTF-8, fits
the available measured label width, and retains each full action path.
Tests and QA no longer read or write the user's recent history.
