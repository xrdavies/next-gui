The boxed context stays at a stable address; the owning connection unregisters
before releasing it and moves with its worker. No process-global routing or
unsafe Send/Sync implementation. Ordinary bound values use expanded SQL, matching
upstream `sqlitedb.cpp` / `MainWindow::logSql`; trigger events retain callback text.

User/Application/Error/All categories show full selectable read-only text. Clear
and atomic export apply to the selected category; 200 entries per category and
eviction counts are visible. The visible dock refreshes when trace revisions change.
Unchanged text restores selection/viewport; new text reveals the end. Export blocks
while SQL runs so the worker-owned database cannot escape the output-path guard.

Key/rekey/hex-key PRAGMAs, ATTACH KEY and key-bearing file URIs redact before storage,
including percent-encoded parameter names and SQLite's `%00` name truncation.
Execution errors from sensitive batches omit details. Ordinary bound data remains
visible, as it is in DB4S. Process-global SQLite diagnostic messages are not wired;
the Error view contains application/execution failures.

Shared `Ui::set_text_area_read_only` blocks typing, paste, deletion, undo/redo and
IME while retaining focus, selection, navigation, copy and scrolling. Programmatic
setters still update text; default TextAreas stay editable. No native a11y claim.
