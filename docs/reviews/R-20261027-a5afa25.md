## Scope and implementation

Compared the upstream DB4S FindReplaceDialog and Scintilla search contract: literal
case-insensitive default, exact-case, whole-word, wrap, backwards, selection-only,
regular expressions, Find Next/Find All/Replace/Replace All, F3 and Shift+F3.
The new `sql_search` engine uses Unicode scalar ranges to match the shared TextArea,
Unicode PCRE2 with UCP, explicit match/depth limits, capture replacement (`\0`–`\9`)
and escape handling. Find All is rendered by the shared multi-range TextArea
highlight API while preserving the active selection. Changes are prepared before
editing and are one TextArea undo operation. SQL-tab/project transitions clear the
transient search scope. At 800×600, the overlay hides only extra/project toolbars
while open and restores their state after closing.

The shared framework now carries F1–F24 through all winit backends as a typed
`KeyCode::Function` variant; e28 binds F3 and Shift+F3. TextArea highlights retain
selection/history and clear after edits, undo/redo or programmatic replacement.
