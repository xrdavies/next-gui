## Original behavior and implementation

[Original settings](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/Settings.cpp)
and [preference controls](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/PreferencesDialog.ui)
define five independent toolbar groups and icon/text/beside/under/follow choices.
The example persists these choices with original defaults; Cancel retains actual
settings. Shared ButtonIconLayout/API/DSL retains live accessible names, disabled
state and keyboard behavior. Follow style uses the documented macOS/Windows
[Qt icon-only fallback](https://doc.qt.io/qt-6/qtoolbutton.html#toolButtonStyle-prop);
Unix desktop integration is pending.

The cell toolbar now imports a bounded file into a typed draft, exports original
read-only bytes or validated draft bytes through staged replacement, sets a draft
to NULL and invokes existing JSON indentation. Database/journal destinations are
guarded; import does not write until Apply. Large-file streaming and complete
original format/indent validation remain. A restored preference Select now syncs
to the scene; the new pixel-node assertion covers the visually found failure.
