## Scope and implementation

The shared Table now stores an inclusive row range in addition to its active row.
A body click resets a one-row range; Shift+Up/Down extends it without changing
keyboard focus; paint uses the range for the selected background. Public APIs
return the range, set it after rebuilds, and serialize selected rows as TSV.
e28 stores start/end in the transient BrowseTab state and restores them after UI
rebuilds. Cmd/Ctrl+C uses TSV only when the browse table has focus; text-area copy
keeps its existing Unicode selection behavior.

No database writes or clipboard data is stored in project files. Range selection is
read-only and cannot mutate the current transaction.
