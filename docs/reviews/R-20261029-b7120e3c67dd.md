## Changes and reference

The editor is now independently visible above the lower Log/Plot/Schema/Remote
pages, matching the topology seen in the original native window and
[MainWindow](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/MainWindow.cpp).
Both regions have close actions; View can reopen them without discarding a cell
draft. Hiding either region reclaims its space; hiding all docks reclaims main width.
Preferred editor/lower and Plot controls/chart ratios survive adaptive constraints
and project JSON/native XML extension round trips. Canonical Qt dock state is still
not decoded.

Shared Tabs support a bottom strip through theme/default constructors and the DSL;
the default top strip is unchanged. Exhaustive external `TabsStyle` literals must
add `strip_at_bottom` or use defaults. Lower tabs use content widths, overflow
arrows and keyboard reveal. Rebuilding a selected tab retains focus, and selection
snapshots now trigger a rebuild so the dock header/minimums follow actual content.

Plot controls and chart have a vertical splitter, as in the original
[PlotDock UI](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/PlotDock.ui).
Controls scroll independently; the chart stays visible when a control receives
focus. Narrow layouts reserve enough chart height for readable axes; some options
and editor actions require scrolling/Tab at800×600. The single horizontal toolbar
retains independently toggleable action groups and reclaims two former rows;
main tab titles also scroll rather than dividing into clipped equal widths.

A shared dock-scroll ID had been overwritten by later hidden pages. Separate IDs
now capture only laid-out regions, preventing hidden zero extents from erasing a
retained60px Plot offset. The regression fails before this correction and passes
after it. Full tests also exposed a real f32 clamp inversion at smaller heights;
maxima are now bounded below by minima. No database engine or dependency changed.
