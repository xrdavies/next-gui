## Scope and implementation

Shared Table now retains a fixed directional anchor while Shift selection extends,
shrinks or reverses; public range getters return ordered copy bounds. Arrow
navigation reveals active columns without resetting horizontal scroll. e28 keeps
selection direction and grid focus across rebuilds. Opt-in `TableStyle::drag_select`
selects rectangles using the same scrolled/frozen geometry as painting; default
tables retain body panning. e28 polls a drag selection after release, avoiding an
intermediate rebuild that loses the drag or overwrites the new cell editor value.

All platform hosts expose HTML clipboard access through WindowCtx. e28 exports
quoted TSV plus escaped HTML, keeps an internal raw typed matrix and recognizes it
only via a unique HTML stamp. Header and SQL copies use Cmd/Ctrl+Shift+C and
Cmd/Ctrl+Alt+C. Raw preview snapshots preserve storage classes, invalid UTF-8 TEXT
and BLOB bytes; payloads above 8 MiB spill to a shared temporary file. Spool writes
are buffered and floating-point bits survive serialization. This is a typed payload
budget, not a total process memory limit; display strings and an explicit large
clipboard selection still consume memory.

Paste uses the existing quoted CSV parser with a tab delimiter. External NULL is
text, one source cell fills a selected rectangle, and every target record receives
one UPDATE. Savepoint rollback protects the whole matrix from constraints, stale
records and trigger-induced record loss while preserving earlier unwritten edits.
Cut copies first, then atomically clears nullable cells to NULL and required cells
to empty TEXT. Neither action commits the database.

Tab operations and form navigation guard cell drafts in state methods, return query
errors, and restore the original tab/page on failure. Cross-page form navigation
retains its column, empty results stay unselected, and refresh clamps offsets after
filtered totals shrink. Foreign-key navigation preserves raw TEXT bytes and rolls
back a failed tab transition. CSV decoding tests now cover malformed code units,
surrogates and non-BMP text; UTF-32 BOMs produce an explicit unsupported error.

Reference inspected: upstream v3.13.1
[ExtendedTableWidget.cpp](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/ExtendedTableWidget.cpp),
particularly clipboard provenance, selection fill and cut behavior. Matrix bounds
remain stricter than upstream clipping; mismatch confirmation is still absent.

## Findings repaired in this range

### R-20261027-5e23229548d4-F01

**Repeated Shift ranges lost their anchor, and a rebuild lost grid focus.**

- Status: verified; severity: P1; owner: codex; platform: shared/e28.
- Location: UI `key_table`, table setters, e28 `poll_selection_changes` / `do_rebuild`.
- Introduced by: a54e792 and the earlier rebuild path.
- Evidence: the old handler reset the range start to the previous active cell on
  every step and normalized away direction. The e28 test formerly refocused the
  table manually between steps, hiding the focus defect.
- Resolution: 15d4a96 and 5590dfb retain anchors, normalize only getters, preserve
  focus, defer drag polling and clear stale selection ranges.
- Verification: six framework regressions and e28 backwards/rebuild/drag tests pass.

### R-20261027-5e23229548d4-F02

**Paste changed literal NULL and could leave a primary-key row partly updated.**

- Status: verified; severity: P1; owner: codex; platform: e28/all.
- Location: state `paste_browse_tsv`; DB `update_cells`.
- Introduced by: 36b7a52.
- Evidence: raw splitting ignored quoted tabs/newlines; the NULL string became
  SQL NULL. Updating an INTEGER PRIMARY KEY before subsequent cells caused later
  per-cell statements to match no record, with no affected-row error. The original
  test did not exercise rollback or a real out-of-bounds selection.
- Resolution: 7df9386, eb581ec and 7439f7c use quoted parsing, typed stamped copies,
  one UPDATE per row and atomic paste/cut with an affected-row check.
- Verification: constraint failure on the second row, prior pending edits, trigger
  deletion of a later row, PK+CHECK updates, quoted TSV, reversed fill, nullable/NN
  cut and typed round trips all pass.
