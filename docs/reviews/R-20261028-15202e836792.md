## Scope and behavior

The public platform snapshot uses owned Core Foundation objects on macOS,
GetLocaleInfoEx on Windows and private/thread-local POSIX locale objects on Linux.
No process-global locale changes or new package versions. Linux reuses the already
locked libc dependency and respects LC_ALL, LC_NUMERIC, LANG precedence. Unicode
symbols are copied before native objects are released.

The shared CSV parser snapshots numeric metadata. Strict grouping normalization
and exact i64 parsing precede finite real conversion; unsupported values retain
raw text. Opting in binds localized integers/reals before SQLite affinity, matching
the original workflow. Opting out keeps raw insertion while C-locale inference
recognizes correctly grouped numbers. The validated streaming snapshot retains
its numeric conventions through confirmation and worker insertion. Defaults,
missing fields, savepoints and completed-file cancellation behavior are retained.

Primary reference: [original import workflow](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/ImportCsvDialog.cpp),
[QLocale numeric behavior](https://doc.qt.io/qt-6/qlocale.html),
[CFNumberFormatter](https://developer.apple.com/documentation/corefoundation/cfnumberformatter).
