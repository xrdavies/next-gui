## Implementation and reference

ColDef stores the first inline REFERENCES clause, including all associated deferral clauses. The AST boundary validates exactly the requested constraint categories; it cannot inject a column, table constraint, other policy or SQL tail. Rebuild replaces/removes only that FK and its deferrals, preserving names and interspersed constraints. CREATE and ADD share validation. Existing legacy definition callers retain original FK clauses. The parser boundary works around sqlite3-parser0.15's dropped named deferral by inserting an AST-only temporary CHECK to consume the name, then removing that node and restoring its name on DEFERRABLE. ## Findings

### R-20261028-df5946de66c9-F01

**The pinned parser silently omitted a named DEFERRABLE clause**

- Status: verified
- Severity: P2
- Owner: grok
- Platform: e28 / all
- Location: `table_sql.rs::parse`, pinned sqlite3-parser0.15 `ccons ::= defer_subclause`
- Introduced by: parser integration in the rebuild path; upstream grammar does not consume the pending constraint name for Defer.

`v REFERENCES parent(id) CHECK(v>0) CONSTRAINT timing DEFERRABLE INITIALLY DEFERRED` is valid SQLite. System SQLite3.54 probe accepted an invalid child insert until transaction end. The pinned parser's AST omitted the named Defer node entirely; its grammar leaves `constraint_name` set and skips that node. Before fix, the metadata regression failed at `foreign_key_clause.contains("INITIALLY DEFERRED")`, and an unrelated rebuild could emit an immediate FK instead of the original deferred FK.

Fixed and verified in `df5946de66c93f0ca751c77ea122063003ed0d51`: protected AST parsing restores every named deferral and validates restoration counts. A real migration with an existing deferred violation, unrelated type edit, further invalid insert and failed/repaired COMMIT confirms the timing survives. Unicode names/comments/literal lookalikes and multiple deferrals round-trip; namespace, full workspace, strict and GUI checks pass. Probe log `/tmp/next-gui-column-fk-parser.log` records the original missing AST node. This finding is verified.
