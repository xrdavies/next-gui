## Implementation and original behavior

Original [mainTabSelected](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/MainWindow.cpp#L1355)
sets Edit Cell read-only when leaving Browse. The example now distinguishes
read-only Browse previews from writable drafts and SQL snapshots. Structure and
Pragmas disable column/type/value editing and Apply/Discard; Text/Hex/JSON/image
viewing and selected copy remain available. Returning to editable Browse reloads
its typed selected value. Generated cells, read-only databases and selections
without a supported row identity also display their existing write limitation.
This does not implement original primary-key/custom-row-identity editing.

The source marker prevents JSON formatting from becoming a false Browse draft.
Real Browse drafts remain drafts even during a pending tab change, block mode
replacement and restore the previous page. Backend Apply enforces page/source
ownership. Existing transaction recovery errors retain their ordering and detail.
Read-only widgets no longer write stale text into model state during Pragmas
rebuilds; the new regression found and verifies that failure.
