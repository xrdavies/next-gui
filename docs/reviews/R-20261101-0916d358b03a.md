## Change and primary reference

Schema insertion now handles database roots and field SELECT queries, following
all eight SELECT/qualification/quoting option combinations. Generated FROM targets
qualify the selected source when temp/main/attached resolution would otherwise
select a same-named object from another database. Name insertion retains the
chosen preferences. Each insertion is one SQL history edit; Undo restores the
prior text and selection. It never executes generated SQL automatically.

Browse column-filter menus offer Use for Conditional Format for nonempty filters,
Clear All Conditional Formats for empty filters, and the column-scoped manager.
Validation precedes changes; first-match priority and other columns/sources survive.
Project changes do not write database data, including on read-only connections.
Closing the manager restores the filter's fresh input, selection, history and focus.
Stale filters, source identities, busy connections and cell/external/IME drafts are
guarded. This target retains the existing orange default; upstream serial palettes
and the Browse cell context entry are outside this acceptance target.

**Attaching an empty database did not trigger a project Save prompt**

- Status: verified
- Severity: P2
- Owner: codex
- Platform: all
- Location: `state.rs::project_snapshot`, `refresh_schema`; `db.rs::database_files`
- Introduced by: existing attachment/project checkpoint implementation; exact initial SHA not isolated
- Fixed: `781ffa32049ac6022ea0fd43a7e045b3c6c3c666`
- Verified: `0916d358b03aa6529afddc51a698c35eced5ff1a`

Before the fix, attaching an empty file could leave every serialized checkpoint
field unchanged. Save/close therefore missed a changed attachment set; reconnecting
a different file under the same alias had the same identity gap. A pre-fix runtime
regression failed with `attaching an empty database must trigger the project Save prompt`
(`/tmp/next-gui-attachment-project-before.log`).

The existing catalog refresh now caches attachment aliases and raw filename bytes;
project dirty comparison includes that cached identity. The cache remains stable
while a background worker temporarily owns the live connection. Detach and Close
reconcile it. This does not add an incompatible persisted ProjectFile field: live
attachments already belong to native project XML. PRAGMA filenames preserve bytes
rather than introducing a new UTF-8 requirement.

Regression checks empty Attach, saved clean checkpoint, parked connection, another
file under the same alias, JSON save/reopen, volatile Attach/Detach returning to
the saved set, Close, and unchanged zero-byte files. Focused and full tests pass.
Invalid-byte OS path attachment is not claimed as macOS runtime coverage.
