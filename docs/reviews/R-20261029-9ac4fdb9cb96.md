## Scope and reference

Read/write the original table attribute `plot_x_axis` and `plot_y_axes` children
`y_axis`/`y2_axis`, including name, line_style, point_shape, colour and active.
Named sources preserve namespaces and settings for tables without open Browse tabs.
Recognized series retain unknown attributes/children, and unrecognized axis children
survive saving. Missing optional style fields in older local projects inherit their
previous global defaults; a source's later style edit does not leak into other sources.

The [official MainWindow source](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/MainWindow.cpp)
defines these fields; the [PlotDock source](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/PlotDock.cpp)
confirms category bars and the hidden ssDot offset in shape numbering. Imported
per-series attributes are honored directly. Line/marker controls display the selected
series rather than an unrelated global default, and polling alone never modifies it.

The canonical DB4S writer emits #RRGGBB colors; these are validated before use.
The local next_gui extension takes precedence for a matching source because it can
represent a real column named Row # and numeric Bars, which native fields cannot
represent unambiguously. Numeric Bars falls back to Line for original readers;
SQL source configurations remain extension-only. Legacy ssDot is approximated by
Disc and reported as unapplied; unknown style numbers are retained and reported.
Noncanonical QColor spellings and translated virtual Row # names remain unsupported.

The first full check failed because the new attached-schema test used :memory:,
which the existing project safety rule correctly rejects as nonpersistent. Replaced
only that fixture with a temporary file; focused and final checks pass. Earlier
intermediate runs are not the final source evidence.
