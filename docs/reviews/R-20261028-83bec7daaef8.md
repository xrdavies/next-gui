## macOS parity and implementation

The existing rfd multiple-file picker feeds native PathBuf values into a checked,
virtualized file list. Shared target or separate per-file targets survive switching;
Select/Deselect All and Match Similar compare parsed column names using the chosen
CSV options. File names lead list rows for legibility; full native paths remain in
state and selected-file accessibility text. No new dependency or framework fork.

An explicit batch operation handles original Yes/No/YesAll/Cancel confirmation,
default No, per-table acceptance, unselected remainders and retryable failures.
Successful or skipped sources are hidden. Completed files are marked before UI
refresh so a refresh failure cannot duplicate imports. Cancel/failure retains the
current unfinished file. Confirmation preview uses the exact pending data snapshot.
An explicit trigger ROLLBACK clears progress and selections and requires deliberate
reselection after recovering the transaction; it never silently reimports sources.

The original source defaults are now header off, trim on and separate tables off
when no import preferences exist; existing saved settings retain their values.
A synchronous full-file parse is still retained in memory; worker progress,
cancellation and streamed insertion are the next import gap.

Primary reference: [v3.13.1 ImportCsvDialog.cpp](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/ImportCsvDialog.cpp)
(accept/selectFiles/selectedFileChanged/selectAll/matchSimilar/importCsv),
[Settings.cpp](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/Settings.cpp)
(importcsv defaults). The original default conflict strategy also inherits table
ROLLBACK policies; the selected Abort behavior intentionally overrides that bug.
