## Implementation and compatibility

SQL result CSV/JSON buttons open the same format controls as table export in a
compact modal without the table chooser, matching the
[original dialog workflow](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/ExportDataDialog.cpp).
The dialog owns only column names and an Arc to the completed result file;
preview pages are not copied. Serialization now captures raw SQLite CellValue
rows once and shares the formatter with table exports, using buffered output.
No SQL statement is executed by this export route. Destinations stage and sync
before per-file atomic replacement, preserving DB-path guards and no-clobber.

Original BLOB formats replace the prior hex display representation: JSON uses
base64; CSV uses printable UTF-8 or base64. Nonfinite JSON becomes null, invalid
TEXT uses replacement characters for JSON, exact int64 remains exact. An original-
format assertion failed before implementation and passes afterward. Obsolete
save helpers removed after all callers migrated. Preferences are shared with
File exports. Native pickers/input and large-export responsiveness remain open.
