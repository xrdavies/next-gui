## Review scope and API migration

The platform enum adds `KeyCode::PageUp` and `PageDown`. All three desktop hosts
map the corresponding winit named keys in the existing key-event path, preserving
press/release and modifiers. This expands a public enum: external exhaustive
matches need new arms. All in-repo Office matches were migrated; platform docs
record the caller change. An initial workspace check caught unhandled example
matches; the final workspace checks pass after their migration.

The shared UI enum adds Table PageUp/Down and SelectPageUp/Down. Plain keys collapse
the range; Shift variants preserve the original anchor while extending/reversing
it. The live viewport determines the step. Existing key behavior remains intact.

With the browse grid focused, e28 plain page keys call the same guarded full-result
navigation as the buttons. Ctrl/Command+Home/End calls First/Last. Other focus,
overlays, confirmation dialogs and unrelated modifier combinations are not
intercepted. Synthetic tests invoke the helper used by the actual Event::Key
callback; they do not establish native key delivery. [Provenance](assets/R-20261027-3f3153b4c200/PROVENANCE.md)
records capture sources and hashes.

No new unresolved implementation defect was found in this slice.
