## Scope and macOS parity

[Scintilla word commands](https://www.scintilla.org/ScintillaDoc.html#SCI_SETWORDCHARS) use character classes. The shared TextArea now exposes WordLeft/Right, SelectWordLeft/Right and DeleteWordLeft/Right. Runs group Unicode alphanumeric/underscore, whitespace or punctuation; grapheme clustering keeps word targets outside combining and emoji clusters. The already locked unicode-segmentation 1.13.3 package is reused as a direct dependency; no version or package added to the lockfile. e28 maps Option on macOS and Ctrl on Windows/Linux, refreshing completion after word deletions. Composing text is left to IME; read-only text permits movement and blocks deletion.

New UiKey enum variants require external exhaustive matches to add branches. Existing Office examples keep their mappings and compile; they do not automatically acquire e28's platform shortcuts. [API notes](../a11y-baseline.md) and example README document this scope. Ordinary character movement/deletion, pointer/vertical grapheme behavior, CR-only lines, complex-script layout and full native editor acceptance remain separate gaps. Boundary scans are synchronous with an explicit profiling shortcut comment. No database writes, project format or rendering changes.
