## Root cause and change

The original single row of line/marker/style/action controls exceeded a narrow
Plot dock. Focus reveal scrolled the entire containing dock horizontally to reach
Copy, leaving most of the chart outside the viewport. Source/legend and style/action
controls now split into rows at constrained widths; chart height accounts for these
rows. Plot reserves a usable minimum width within the available main/dock split.
Adaptive sizing leaves the saved preferred body ratio untouched, so resizing back
restores the user's preference. Existing other dock sizing is unchanged.
