## Original behavior and changes

Original [EditDialog](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/EditDialog.cpp)
uses a mode combo, validates/formats JSON/XML and provides Ctrl/Command+Return Apply;
[MainWindow evaluation](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/MainWindow.cpp#L1031)
computes SQLite SELECT expressions. The example now offers Text/Binary/Image/JSON/XML/
Evaluation through the house Select. Pending keyboard choices survive rebuilds while
open, and confirmation changes the view without evaluating SQL.

XML uses pinned roxmltree0.21.1, whose [MSRV is1.60](https://github.com/RazrFalcon/roxmltree/blob/v0.21.1/Cargo.toml).
Existing quick-xml alone did not validate namespace/name/entity rules. XML parsing
accepts internal DTD entities with no external resolver; [parsing options](https://docs.rs/roxmltree/0.21.1/roxmltree/struct.ParsingOptions.html)
provide the node bound. Indentation inserts whitespace into the original tokens;
mixed content, CDATA, xml:space preservation and entity definitions are retained.
Preview baselines preserve original storage bytes and avoid false drafts. Invalid
JSON/XML can leave its format view or export its current draft without writing it.
Indentation in editable text uses the shared replacement/Undo path.

Evaluation reads the current connection only on explicit Apply, keeps SQLite storage
classes, and reuses prepare_single_statement for tail/parameter protection. Source,
page, generated/row-identity and database write guards run first. Invalid UTF-8 TEXT
returns an error with a CAST-to-BLOB alternative instead of panicking. Typing into
NULL selects TEXT/BLOB as appropriate; explicit NULL clears the draft.

Native review exposed an existing refresh path that cleared the editor after a
successful update. Apply now reloads the visible updated record by rowid, retains
its format view and keeps shortcut focus on the result. Records removed by the
filter/current page leave no misleading selection. Sort/filter regressions and
actual copied native results verify this correction. Earlier v12 native numeric
checks were rejected after visual review; all final evidence was rerun at v15.
