fixed number format and the original help page. Keyboard input stays in the active
context menu. Global plot settings persist through the existing JSON/native XML
extension; style toggles preserve full-data buffers, current view and SQL execution
identity. Save now rejects a missing idle connection before opening a picker.

removing font-glyph dependence in Plot and the existing View menu. Context menus
measure labels/check space within the viewport. Fixed numeric labels follow the
[original v3.13.1 PlotDock](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/PlotDock.cpp)
precision rule: visible center>999 and span>10 uses0 decimals, otherwise2. Date/time
and category labels retain their existing behavior. Original general-format Qt
conversion and automatic tick selection are not fully reproduced.
