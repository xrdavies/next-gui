## Implementation and reference comparison

The original parser accepts quoted segments inside fields and ordinary text after
a closing quote. The shared parser now accepts both, including fragmented/custom
Unicode input. The first20 raw records determine maximum column count and generated
names, matching original schema sampling. Missing cells do not force type TEXT;
preview pads display cells while snapshots preserve raw row lengths.

Insertion distinguishes an absent field from an explicit empty string. Absent
fields bind NULL; existing-table defaults and missing-value policies apply to
explicit empty cells. Savepoint rollback, constraints and conflict handling stay
shared. A successful file records its target as accepted, including a table just
created in the same batch, matching the original workflow. Legacy clipboard paste
still validates rectangular selections before mutation.

Input with extra fields after the sampled schema is rejected before mutation;
it is never silently truncated. Empty quoted EOF, blank-line and less common
parser/codec/locale edge cases still need complete original comparison. Existing
correct REAL promotion and strict codec validation remain. No new dependency or
framework API was needed.

Primary sources: [original CSV parser](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/csvparser.cpp),
[original CSV workflow](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/ImportCsvDialog.cpp).
This is source-based comparison, not execution of the original binary.
