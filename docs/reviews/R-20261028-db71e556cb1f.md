## Implementation and continued goal

CSV files now decode in bounded chunks and use the same parser as Unicode clipboard
text. The preview reads20 raw records (19 data rows with a header), limits displayed
cell text to1024 characters and shows inferred column types. Empty header names
fall back to field1, field2, etc. Full import validates the entire input before
mutation. Its parsed rows are still retained in memory; cancellable streaming
insertion/progress remains pending.

The options/preview layout keeps actions at the bottom and options scrollable in
small windows. Custom separator/quote characters or scalar code points, trim,
type detection, missing/default policies and conflict strategy reach real imports.
Existing tables use writable-column position and require confirmation; Cancel is
the initial/default action. Savepoint failures preserve prior pending work. Last
accepted settings persist; changing the global delimiter updates the next import.
