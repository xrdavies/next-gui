## Implementation and reference

[DB4S v3.13.1 ForeignKeyEditorDelegate.cpp](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/ForeignKeyEditorDelegate.cpp)
defines a table combo, referenced-ID combo, clauses edit and Reset inside the cell.
The example mounts that workflow as an ordinary Row under the shared Table editor.
The parent selector uses only the wizard's SQLite schema; self-reference candidates
use draft columns/name. Ordered target-column completion includes primary/unique
combinations, supports explicit SQL column lists and preserves complete composite
references. This avoids the original delegate's first-target-only truncation.
Unchanged parts retain raw SQL. Clauses/deferrals parse independently of local arity,
while the existing complete validated SQL boundary still governs preview/Save.
Malformed references retain the existing raw text fallback for repair.

The framework accepts a Row editor, lays it out at cell geometry, and routes keys
from descendants. Internal navigation visits child controls before leaving the cell;
composition/popups retain their normal precedence. Applications can query editor
ownership. No dependency/config/platform source change.

Final visual review corrected small-window clipping by revealing the active reference
column. Tests also caught empty reference completion selecting a first explicit column,
plus removed-row Tab/pointer identity changes; final behavior has regressions covering
these paths. Initial method/type/borrow test errors and outdated single-input assertions
were corrected. Required checks pass.
