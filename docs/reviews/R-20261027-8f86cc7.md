## Scope and implementation

Browse Form View now advances from the last visible row to the first row of the
next 500-row page and moves back from the first row to the last row of the previous
page. Navigation uses the existing filtered `total_rows` and rowid-backed refresh,
keeps the selected column, and leaves the current page unchanged at either global
boundary. The form toolbar reports the global filtered record number instead of a
page-local number.
