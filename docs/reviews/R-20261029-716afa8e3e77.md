## macOS parity and implementation

The original v3.13.1 [MainWindow.ui](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/MainWindow.ui)
uses an icon SQL toolbar and requests TextBesideIcon for the main/Project toolbars.
This increment provides compact icons and full help; original display modes and
configuration remain required for complete parity.

Shared Button now accepts a house icon without changing existing text builders or
public style structs. Toolbar icon builders return the actual Button ID, retain the
label for accessibility and derive wrapped/clamped help from its live accessible
name. Theme/density, focus, pointer routing and disabled colors use the existing
Button paths. Clearing the icon restores authored text sizing. Validated Button
icon literals reach DSL; new Database/Undo/Step/Code enum variants require new arms
in exhaustive external IconName matches. No dependency was added.

The browser uses grouped icon actions in its main and SQL rows. Existing IDs and
handlers, View visibility groups, document protections and semantic Execute/Write
colors remain. Unsupported New/Open shortcut labels were removed during review;
SQL help lists only connected shortcuts. The redundant SQL number label is omitted
because the adjacent tab already identifies it. Text controls elsewhere retain
their appearance, checked with fresh Office binaries after the workspace build.
