## Review scope

Compared against official v3.13.1 `TableBrowser::navigatePrevious/navigateNext`
and [ExtendedTableWidget::numVisibleRows](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/ExtendedTableWidget.cpp#L988).
The shared counter excludes rows exposed by less than half their height and uses
the current widget viewport and scroll position. Previous/Next moves by that
count minus one (minimum one), rather than loading the next fixed 500-row page.
The existing guarded goto path handles query failures, bounds and cross-cache
selection. Form mode moves one record when there is no grid viewport.

The old fixed-page controls and page-number label were removed; First, Previous,
Goto, Next and Last now share the bottom row. The cell dock shows the one-based
global record number. Existing boundary tests were migrated to the new semantics.
No host event API or dependency changed, and other Table callers retain behavior.

No new unresolved defect was found in the implementation slice. See
[capture provenance](assets/R-20261027-5c9c20d208ae/PROVENANCE.md).
