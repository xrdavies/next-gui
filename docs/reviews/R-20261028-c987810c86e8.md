## Scope and macOS parity

A Cartesian tile now extends the existing Chart instead of introducing a second
widget hierarchy or rendering dependency. Shared f64/Arc samples, finite axis
ranges, ISO date/time parsing, numeric/category ticks, dual Y scales, line/marker
styles, point/range highlighting and bounded RGBA output feed the same Scene image
path in Soft and Metal. Screen-column reduction retains straight-line endpoints,
extrema, gaps and source order. Mutable access invalidates retained rasters;
unchanged syncs reuse them. Gauge/Trend paths explicitly clear reused image nodes.

Wheel zoom, drag pan, axis constraints, keyboard fit/navigation and source selection
have matching retained state. Release commits a point click; focus loss cancels it.
Sessions restore only for the same shared source buffers/axis roles, and the browser
retains matching view/focus across rebuilds. Full labels and keyboard operations are
exposed through the framework accessibility name, without claiming a native bridge.

Step semantics follow the [QCustomPlot graph contract](https://www.qcustomplot.com/documentation/classQCPGraph.html).
Calendar conversion uses Gregorian400-year arithmetic checked against the
[primary date algorithm reference](https://howardhinnant.github.io/date_algorithms.html).
The [official3.13.1 release](https://github.com/sqlitebrowser/sqlitebrowser/releases/tag/v3.13.1)
provides the now verified original native baseline.
