## Review result and repaired cases

No unresolved must-fix defect was found in the reviewed e28 local data paths after these repairs. This is not exhaustive review of the 22k-line shared widget implementation.

1. **Save/export data loss (prior P0s):** Live backup includes WAL/memory data; dumps stream every row as SQLite values. Round trips cover 600+ rows, NULL, empty TEXT, quotes/NUL/Unicode, BLOB, REAL/infinity, generated columns, rowids, triggers and AUTOINCREMENT sequence. Existing destinations are refused by New/Save As; import and schema edits use savepoints.
2. **Unmarked pending writes:** SQLite transaction state replaces row-count/schema-version guesses, catching PRAGMA and attached-schema writes and partial failed batches. Explicit COMMIT/ROLLBACK clears the marker; native close honors it.
3. **Browse can execute writes:** Filters previously passed through a batch executor. Browse now prepares exactly one read-only query; `1; DELETE FROM t; --` is rejected and the row survives.
4. **Wrong row or destination:** Generated `rowid` columns cannot become grid identities; dump uses an unshadowed alias. Export rejects the main/attached database and WAL/SHM/journal destinations. Refresh/page/sort clears stale edit selection.
5. **Incomplete local workflows:** Browse pages reach all records; insertion supports Default/NULL/Value and rolls back through Revert. Full final SQL results export from a private snapshot without rerunning DML. JSON projects restore browse tabs and resolve relative DB paths; memory projects require Save As first.
6. **Dead controls and clipped dialogs:** Vacuum/Integrity/Save Project toolbar actions are wired, confirm-drops preference is honored, and dialog Save/Cancel buttons are above the status bar with hit-test coverage.
7. **Input and cancellation:** Secret fields mask content and disable copying/accessibility value leakage. SQL editor supports IME composition; Execute Line uses the Unicode caret. File-dialog cancellation does not write a fallback file. Stop interrupts the worker and returns the live connection.
