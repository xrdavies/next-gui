## Scope and macOS parity

The DB4S [SqlUiLexer](https://github.com/sqlitebrowser/sqlitebrowser/blob/v3.13.1/src/SqlUiLexer.cpp) provides the descriptive variants. e28 now displays one registered overload and its own parameter help at a time, initially choosing a signature suitable for the current argument. Previous/next arrows and Cmd/Ctrl+Shift+Space browse all alternatives; the latter also reopens dismissed help. Clipped text scrolls via wheel or Cmd/Ctrl+Shift+PageUp/PageDown. Ordinary document page navigation stays intact.

Shared `set_text_area_hints`, `text_area_hint_page`, `cycle_text_area_hint`, and `scroll_text_area_hint` extend the existing passive hint. A private session state retains choice/scroll/dismissal across refresh/rebuild, resetting preference when argument context changes. Controls remain outside the focus order and keyboard callers keep editor focus. The popup's accessible name includes its position and current help; the native accessibility bridge remains a broader outstanding gap. No database write, dependencies or project-format changes.
