## Behavior and framework parity

WindowCtx now reads/writes house RgbaImage through all three window hosts. Existing
long-lived arboard handles retain Linux ownership. Reads distinguish missing image
contents from OS/validation errors, and writes validate dimensions and a128 MiB byte
budget before crossing the platform boundary. Copy and focused Cmd/Ctrl+C render
the visible chart viewport with its existing palette, selection, legend and styles;
no SQL replay or database mutation is needed. Save reuses the same image helper.

The existing arboard dependency enables image-data. Its broad image constraint
otherwise selects a codec newer than the workspace compiler; pinning image0.25.8
keeps the supported Rust1.86 toolchain (upstream declares
[Rust1.85](https://github.com/image-rs/image/blob/v0.25.8/Cargo.toml)). The pin has an
explicit upgrade comment. Image decoding adds the necessary transitive codecs.
Normal test runs no longer overwrite the general clipboard automatically; the
native image test refuses to write unless the clipboard contains only our marker.
