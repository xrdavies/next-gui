## Scope and implementation

The Browse Data tab strip now has a Close Tab action. Closing removes the active
browse state and selects the adjacent tab; closing the final tab resets it to one
empty Browse tab so the page remains usable. Closing a browse tab does not touch
SQLite transaction state or the shared cell draft. The compact strip remains within
the existing scroll row.
