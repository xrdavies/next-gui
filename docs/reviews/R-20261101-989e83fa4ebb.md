## Scope

Shared Select accepts immutable indexed sources and reads only visible option labels.
Selection caches its label, preserves global indices and same-provider rebuild sessions,
and retains the old value on read failure. Home/End/Page keys reach the complete source.
A million-option regression bounds label reads and scene nodes.

Browse foreign keys load all distinct parent values into a typed indexed snapshot on
the existing database connection. Work is cancellable and preserves pending edits.
Same-schema attached/quoted names and implicit composite parent keys resolve correctly.
NULL and integer/real/TEXT/BLOB values retain their storage type, including invalid UTF-8.
An orphan current value remains selectable without changing data. Composite editing
changes only the selected component, as the original delegate does; SQLite validates
the full constraint. Failed or stale edits retain data and drafts. Save All uses the
selected raw value, and primary-key movement restores the resulting record.
