## Scope and implementation

The e28 browse table now accepts Cmd/Ctrl+V when it has focus. A tab-separated
matrix starts at the selected row and column, validates rectangular dimensions and
visible-page bounds before writing, and updates rowid-backed tables inside the
existing savepoint helper. SQLite receives text bindings so normal column affinity
continues to decide storage type; the literal `NULL` maps to SQL NULL. Read-only
databases, views without rowids, empty clips, and an active cell draft are rejected.
The transaction remains unwritten until Write Changes, and a compact application log
entry records the operation.
